# Nexus 评估与验证

## 当前验收标准

服务级：

- Registry health OK；
- Broker health OK；
- Agent registered；
- Device approved；
- job completed；
- exit_code 符合预期；
- output 可验证。

SSH 级：

- `/v3/ssh/authorized-keys` 发布 approved 设备 public keys；
- 各节点 authorized_keys Nexus 管理区块数量一致；
- 至少验证真实 SSH 登录路径；
- VSC userspace Tailscale 使用 `tailscale nc` / ProxyCommand 验证。
