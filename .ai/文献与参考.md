## 核心 API 与 Schema

### 1. Supabase Cloud 表结构 (`devices` & `commands`)

```sql
-- devices 表
CREATE TABLE public.devices (
    device_id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    status TEXT DEFAULT 'offline',
    last_seen TIMESTAMPTZ DEFAULT now()
);

-- commands 表
CREATE TABLE public.commands (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    target_device TEXT,
    command TEXT NOT NULL,
    status TEXT DEFAULT 'pending',
    output TEXT,
    timeout_ms INTEGER DEFAULT 30000,
    created_at TIMESTAMPTZ DEFAULT now()
);
```

## 2026-08-08 v2.6 设备身份 API 与存储地址

Agent 不再保存 API token。设备本机生成 Nexus 专用 Ed25519 keypair，服务器保存公钥和批准状态。

### API 地址

- Global API：`https://nexus-global-api.bings.app`
- 设备注册：`POST /api/device-identities/register`
- 待批准列表：`GET /api/admin/device-identities?status=pending`
- 批准设备：`POST /api/admin/device-identities/{device_id}/approve`
- 拒绝设备：`POST /api/admin/device-identities/{device_id}/reject`
- 撤销设备：`POST /api/admin/device-identities/{device_id}/revoke`
- approved 公钥查询：`GET /api/device-identities/{device_id}/public-key`
- Agent 心跳：`POST /api/devices/heartbeat`
- Broker 领取：`GET {regional_broker}/claim?...`
- Broker 回执：`POST {regional_broker}/complete`

### 存储地址

- Global API 权威身份库：Oracle `/var/lib/nexus-global-api/device_identities.db`
- Supabase 目录/审计镜像：`https://iyqzgmzlykufsbtmykpw.supabase.co/rest/v1/device_identities`
- Linux/OpenWrt 私钥：`/etc/nexus-agent/identity_ed25519`
- Linux/OpenWrt 公钥：`/etc/nexus-agent/identity_ed25519.pub`
- OpenWrt Ed25519 signer：`/opt/nexus-agent/openwrt_ed25519_signer.rb`
- Windows 私钥：`C:\ProgramData\NexusAgent\identity_ed25519`
- Windows 公钥：`C:\ProgramData\NexusAgent\identity_ed25519.pub`
- 完整规范：`docs/DEVICE_IDENTITY_AUTH.md`
