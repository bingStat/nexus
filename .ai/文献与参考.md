## 当前 API

Registry:

- `GET /v3/health`
- `POST /v3/devices/register`
- `GET /v3/devices/{device_id}/public-key`
- `GET /v3/ssh/authorized-keys`
- `GET /v3/admin/devices`
- `POST /v3/admin/devices/{device_id}/approve|reject|revoke`

Broker:

- `GET /v3/health`
- `POST /v3/jobs`
- `GET /v3/jobs?id={job_id}`
- `GET /v3/jobs/claim?...`
- `POST /v3/jobs/complete`

ChatGPT Remote:

- `GET /health`
- `GET /openapi.json`
- `GET /api/devices`
- `POST /api/execute`
- `GET /api/jobs/{job_id}`
